    Exercise catalog

    Library in fitness/exercises/catalog.json — muscles, session type (push/pull/legs), equipment. Toggle availability to control what the planner can pick.

      Today’s workout plan

      Catalog + PPL rotation + last loads + recovery, guided by a ≈4–8 hard sets / major muscle / week volume model (compound overlap counts; not 10–20+). Focus muscles are auto-picked from weekly volume gaps (coach logic on each plan). Goals in fitness/exercises/goals.json.

      Log workout

      One card per exercise. Use + Set for different weights/reps (saved as 50 lbs x 1 x 10, 45 lbs x 1 x 8). Same load for all sets: one set row with Sets = 3. PR is auto-tagged from history on save. Use Log this plan on the Today card to prefill from today’s prescription.
