# Personal Portfolio Website (MVP)

Core personal info + living master-plan outline: interests, systems you work on, wins, and future targets.

## Run

```bash
python3 personal/portfolio/server.py
# http://127.0.0.1:8770/
```

Or open `index.html` directly.

## Verify

```bash
python3 -m unittest discover -s personal/portfolio/tests -v
```
