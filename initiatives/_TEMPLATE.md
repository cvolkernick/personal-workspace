### How to add a new initiative
1. Copy this file to `initiatives/<short-slug>.md` (not `_TEMPLATE.md`).
2. Fill YAML frontmatter: **title**, **status** (`todo` | `active` | `done`), **linked_bets**, **next_action**.
3. Optionally add a matching open item in `strategy/today.md` so it appears in **Today's Focus**.
4. Refresh Orchestra (http://127.0.0.1:8790/) — the initiative shows under Today's Focus → Active initiatives.
