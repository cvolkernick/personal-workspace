# MiKrafts site notes (docs only — no site UI)

Mike emails **cvolkern@gmail.com**. Grok parses the mail, implements the
change, and replies to Mike. There is no Feedback page, form, mailto
widget, or Vercel mail function.

## Email contract

1. **To:** `cvolkern@gmail.com`
2. **Subject** contains `mikrafts feedback` (case-insensitive).
3. **Body:** the notes. No attachment required.

This is not a live Gmail watcher in this package. Grok owns the mailbox
routine.
