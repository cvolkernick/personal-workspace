## Team process (debate, then one executor)
1. Scout: get_accounts, get_portfolio, get_equity_positions on agentic; quotes as needed; sleeve weights via treasury/fund_manager.py or policy; scan watchlist + any research/ reports.
2. Thesis: 40/60 modernized targets + allowlist/themes + watchlist candidates; propose actions or hold.
3. Risk: capital bounds, concentration, trade-or-not, size.
4. Critic: challenge weak ideas; may block or cut size (especially thin-evidence watchlist names).
5. Quorum: Risk OK + Thesis OK; Critic can force hold/size-down. Scout advisory.
6. Executor ONLY places/cancels via Robinhood MCP.

## After decision (required)
Append a full decision with append_decision in treasury/fund_manager.py (or write equivalent JSONL line) including:
- summary, kind (hold|rebalance|deploy|rotate)
- rationale.why_now, rationale.why_not_alternatives
- team_votes for scout/thesis/risk/critic/executor (vote + note)
- actions with symbol/side/notional/status/order_id
- weights_before and weights_after_expected
Then: refresh rh snapshot if practical, run `python3 -m treasury.run_treasury --offline` so FCC updates.

## Output
End with a short plain summary of votes + actions (or HOLD). No questions to the user.
